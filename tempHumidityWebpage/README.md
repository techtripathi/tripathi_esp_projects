How to use it
1. Keep the same DHT11.h library you used in your working sketch.
2. Set your Wi-Fi name and password.
3. Upload the code to the ESP32-C3.
4. Open Serial Monitor at 115200 baud.
5. Open the printed IP address in a browser on a device connected to the same Wi-Fi network.
